# Java Buzz - Website Designing Task (DSL 2026)

**Repository Link:** https://github.com/Code-With-Sami/java-buzz-coffee

## 🚀 Project Overview
This project is a modern, responsive website for "Java Buzz," a premium coffee shop. It features online ordering capabilities, a dynamic blog, and interactive location tracking.

## 🛠️ Technology Stack
- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS 4.0
- **Animations:** Framer Motion
- **Maps:** Leaflet API
- **Icons:** Lucide React

## 📋 Fulfilled Requirements
- [x] Simple and intuitive top navigation bar.
- [x] High-quality Hero section with Call-to-Action.
- [x] Responsive design (Mobile, Tablet, Desktop).
- [x] Menu section with prices.
- [x] Location section with Leaflet Map, Directions, and Parking info.
- [x] Dynamic Blog section using JSON (10 Unique Blogs).
- [x] Warm Brown & Green color scheme.
- [x] SEO Optimized (Sitemap.xml, Robots.txt, and Meta Tags).
